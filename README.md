# MapHeritage

Сайт: главная (`/`), создание карты (`/create`), готовая карта для родных (`/m/<id>`).
Интерфейс по умолчанию на английском, кнопка RU/EN переключает язык. Бот отвечает на том языке, на котором ему пишут.

## Что внутри
- **Три сценария интервью**: путешествие одного человека, малая семья, родословное древо (с боковыми ветками по желанию). Подробно в `SCENARIOS.md`.
- **Импорт GEDCOM**: выбор корня и охвата, геокодинг мест.
- **Композиция**: главная карта на Leaflet, врезки городов, картуш, легенда, роза ветров, масштаб, рамка с градусной шкалой, текстура бумаги, древо или хроника.
- **Подложки** CARTO без подписей: серая, чёрная, цветная, с тонировкой в любой цвет, насыщенностью, яркостью и контрастом. Тайлы идут через свой прокси `/api/tile/...` и кэшируются Cloudflare. Это нужно, чтобы браузер мог прочитать пиксели для экспорта.
- **Настройки оформления**: четыре стиля, все цвета, шрифты, формат, каждый элемент включается и выключается, выбор врезок. Всё сохраняется в карте.
- **Экспорт PNG** 3200 px по ширине.

## Обновление с прошлой версии
1. В репозитории `mapheritage` на GitHub **не трогай `wrangler.toml`**: в нём твои привязки к базе и ИИ. В архиве его нет специально.
2. Удали старую папку `public` и файл `public/assets/mapkit.js`, если он остался (Add file → Upload files не удаляет старое). Затем загрузи из архива папки `public`, `functions`, `lib` и файлы `SCENARIOS.md`, `README.md`.
3. Commit, и Pages пересоберёт сайт сам. Менять базу не нужно.

`wrangler.example.toml` — образец конфига для нового проекта.

## Бот
По умолчанию работает Workers AI (Llama 3.3 70B). Для лучшего качества интервью, особенно в сценарии древа, добавь секрет `ANTHROPIC_API_KEY` в Settings → Variables and Secrets, и тогда бот работает на Claude.

## Заметки
- Подложки CARTO бесплатны для некоммерческого использования. При коммерческом запуске нужен их тариф или другой провайдер (адрес меняется в одной строке в `functions/api/tile/[[path]].js`).
- Редактировать карту может только браузер, где её создали: секретный ключ хранится в нём.
