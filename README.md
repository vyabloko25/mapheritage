# MapHeritage

Страницы: главная (`/`), создание карты (`/create`), готовая карта (`/m/<id>`), планы (`/plans`).
Интерфейс по умолчанию на английском, кнопка RU/EN рядом с названием. Бот отвечает на языке пользователя.

## Обновление с прошлой версии

### 1. База (один раз)
Cloudflare → Storage & Databases → D1 → `mapheritage` → Console. Выполни по очереди **каждую строку** из `migrate-3.sql` (7 строк), если ещё не выполнял.
Если `migrate-2.sql` ещё не выполнялся, сначала выполни его. Ответ «duplicate column» значит, что колонка уже есть, это нормально.

### 1а. Миграция 4 (один раз)
В той же консоли D1 выполни строку из `migrate-4.sql`:
`ALTER TABLE geocache ADD COLUMN kind TEXT;`
Она нужна, чтобы различать города и страны: врезки делаются только для населённых пунктов.

### 1б. Миграция 5 (один раз)
В консоли D1 выполни по очереди обе строки из `migrate-5.sql` — это таблица `styles` для собственных стилей Pro.

### 2. Хранилище для печати (если нужна печать)
Cloudflare → R2 → Create bucket `mapheritage-prints`. Затем Pages → mapheritage → Settings → Bindings → Add → R2 bucket: имя привязки `PRINTS`, бакет `mapheritage-prints`.
Без этой привязки кнопка «Заказать печать» честно пишет, что печать пока недоступна.

### 3. Переменные (Pages → Settings → Variables and Secrets)
Обязательно для Impressum (иначе на странице будут красные пометки «fehlt»):
`LEGAL_NAME`, `LEGAL_STREET`, `LEGAL_ZIP_CITY`, `LEGAL_EMAIL`. По ситуации: `LEGAL_PHONE`, `LEGAL_VAT_ID`, `LEGAL_REGISTER`, `LEGAL_RESPONSIBLE`, `LEGAL_COUNTRY` (по умолчанию Германия), `LEGAL_SMALL_BUSINESS=1` для Kleinunternehmer.
Почта через Resend (resend.com, домен нужно подтвердить): секрет `RESEND_API_KEY`, `MAIL_FROM` вида `MapHeritage <hello@твой-домен>`, `OWNER_EMAIL` — куда приходят заказы печати.
Без ключа Resend письма только пишутся в лог функций — для запуска ключ нужен, иначе не работает сброс пароля.
Защита: секрет `RATE_SALT` — любая длинная случайная строка.
Печать: `PRINT_PRICES` (JSON, по желанию) и `PRINT_DAYS` (например `7–10`).

### 4. Файлы на GitHub
**Не трогай `wrangler.toml`.** Удали старые папки `public`, `functions`, `lib`, загрузи новые из архива вместе с `README.md`, `SCENARIOS.md`, `schema.sql`, `migrate-2.sql`, `migrate-3.sql`, `wrangler.example.toml`, `tools`. Commit.
Папка `functions/api/tile` больше не нужна: подложка теперь своя.

### 5. Проверка
- Открой `/create`: карта рисуется без внешних серверов (данные лежат в `public/geo`).
- Открой `/impressum`, `/datenschutz`, `/agb` и переключи DE/EN/RU. Красных пометок быть не должно.
- Нажми «Забыли пароль?» и проверь, что письмо пришло.
- Если привязал R2: закажи тестовую печать самому себе, в письме будет ссылка на файл.


## Админский вход для тестирования
В Cloudflare → Pages → mapheritage → Settings → Variables and Secrets добавь два секрета (тип **Secret**):
- `ADMIN_EMAILS` = `vasily.yablokov@gmail.com` (можно несколько адресов через запятую);
- `ADMIN_PASSWORD` = пароль для входа.
После передеплоя войди на `/create` обычной формой «Войти» с этим адресом и паролем. Аккаунт создастся сам, сразу с Pro.
У админа нет лимита скачиваний, а в меню аккаунта есть пункт «Тест: переключить на Lite/Pro», чтобы проверить обе версии сайта.
Пароль хранится только в секрете Cloudflare, не в коде. Сменить его — поменять секрет и передеплоить.



## Проекты, шаблоны и свои стили
- У каждого пользователя экран «Проекты» (кнопка в шапке): карточки проектов со стилем, числом людей и мест, датой; в меню карточки — переименовать, дублировать (`POST /api/maps/:id/duplicate`), удалить.
- Новый проект начинается с шаблона: «Личная история» (стиль «Эпоха открытий»), «Семья» («Адмиралтейство»), «Родословная» («Современный атлас», можно сразу загрузить GEDCOM).
- Pro: «Собрать стиль с нуля» — нейтральная основа `BLANK` в `poster.js`, дальше настраивается всё; «Сохранить как мой стиль» — в таблицу `styles` (`/api/styles`), свои стили появляются рядом с пятью стандартными на любой карте.
- Pro: у врезок может быть свой вид — для всех сразу («Вид врезок»: как у карты, один из пяти стилей или свои цвета и рисовка города) или для отдельной врезки в инспекторе.

## Рельеф
Шесть способов, выбираются в «Оформлении» (Pro) и заданы в каждом стиле: отмывка, швейцарская отмывка (окраска + сильная отмывка), послойная окраска, горизонтали, освещённые горизонтали (Танака), штрихи.
Данные: `public/geo/elev.png` — высоты ETOPO10 (NOAA), `public/geo/relief.jpg` — отмывка из тех же высот плюс мелкий рисунок рельефа Natural Earth. Пересобрать: `python3 tools/build_relief.py etopo10_ice_g_i2.bin shadedrelief.jpg public/geo`.

## Врезки городов (OpenStreetMap)
С масштаба врезки 11 и крупнее рисуется сам город: здания, застройка, парки, вода и море, реки, железные дороги и дороги.
Данные — векторные плитки OpenStreetMap (схема OpenMapTiles) от OpenFreeMap, бесплатно и без ключа. Их загружает функция `functions/api/tiles/[z]/[x]/[y].js` и хранит в кэше Cloudflare 30 дней; браузер посетителя к OpenFreeMap не обращается.
Сколько дорог рисовать — настройка «Дороги во врезках» (1–5) и такая же у каждой врезки в инспекторе. При приближении густота сохраняется: добавляются более мелкие классы улиц, с большого масштаба — здания.
Другой источник плиток можно задать переменной `TILES_URL` (адрес TileJSON со слоями OpenMapTiles).

## Подложка
Своя векторная, из Natural Earth (общественное достояние) и рельефа ETOPO5 (NOAA). Ничего не грузится с чужих серверов, поэтому нет вопросов к лицензиям тайлов и к передаче IP-адресов.
Пересобрать данные: `python3 tools/build_geo.py <папка с geojson Natural Earth> <etopo-poly.shp> public/geo`.

## Стили и оформление
Пять стилей: Эпоха открытий, Портолан, Адмиралтейство, Ночное плавание, Современный атлас. Настройки стилей — объект `PRESETS` в `public/assets/poster.js`.
Картуши: рамка, свиток, медальон, блок. Розы ветров: нарядная, простая, портолан, современная. Рамки: градусная шкала, двойная, орнамент, линия.
Маршруты: сплошной, пунктир, точки, двойной, с подложкой, от руки. Значки: кольцо, точка, квадрат, звезда, булавка, городок.
Ещё: румбовая сетка, градусы на полях, береговые линии, мелководье, рельеф, реки, границы, корабли и волны, старение бумаги, свои надписи. Всё это попадает в экспорт.

## Печать
Покупатель выбирает формат (A3/A2), бумагу, раму и адрес. Браузер рисует файл в 300 dpi (JPEG), он уходит в R2, в D1 появляется строка в `print_orders`.
Владельцу приходит письмо с данными заказа и ссылкой на файл, покупателю — подтверждение, что заявка получена. Цена всегда пересчитывается на сервере.
Договор заключается, когда ты отправляешь счёт (так написано в AGB). Оплата пока по счёту, вручную.
Цены по умолчанию — в `lib/print.js`. Поменять без правки кода: переменная `PRINT_PRICES`, например
`{"formats":{"a3":{"price":99},"a2":{"price":149}},"frames":{"oak":{"price":119}},"shipping":{"DE":0,"EU":15,"WORLD":35}}`.
Посмотреть заказы: `SELECT id, email, format, frame, total, created_at FROM print_orders ORDER BY created_at DESC;`

## Юридическое (Германия)
- Impressum, Datenschutzerklärung и AGB с Widerrufsbelehrung — `lib/legal.js`, адреса `/impressum`, `/datenschutz`, `/agb` (`?lang=de|en|ru`, юридически значим немецкий текст).
- Разделы Datenschutz появляются только для включённых сервисов (Google, Resend, R2, Anthropic или Workers AI).
- Шрифты и Leaflet лежат на своём сервере (`public/assets/fonts`, `public/vendor/leaflet`), трекеров и сторонних cookie нет, баннер cookie не нужен.
- Регистрация: галочки «принимаю AGB и Datenschutz» и «мне есть 16», время и версия согласия сохраняются. Новый аккаунт через Google создаётся только после тех же галочек.
- Сброс пароля по почте, «Скачать мои данные» (JSON со всем, что хранится) и удаление аккаунта — в меню аккаунта.
- Ограничения частоты запросов (вход, регистрация, сброс, чат, поиск мест, экспорт, печать) — `lib/rate.js`; IP хранится только как солёный хэш не дольше часа.
- Строгая CSP и заголовки безопасности — `public/_headers`.
- **Тексты — хорошая основа, но не юридическая консультация. Перед запуском покажи их юристу**, особенно AGB, если начнёшь брать деньги за Pro.

## Вход через Google (по желанию)
1. https://console.cloud.google.com → создай проект → APIs & Services → OAuth consent screen: тип External, название MapHeritage, твоя почта.
2. Credentials → Create credentials → OAuth client ID → Web application.
   Authorized redirect URI: `https://ТВОЙ-ДОМЕН/api/auth/google/callback` (добавь и `https://mapheritage.pages.dev/api/auth/google/callback`, если пользуешься этим адресом).
3. Cloudflare → Pages → mapheritage → Settings → Variables and Secrets → добавь секреты `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET` → Retry deployment.
Кнопка «Войти через Google» появится сама.

## Планы
Лимиты задаются в `lib/plans.js`. Сейчас:
- **Lite**: все пять стилей, формат, элементы, врезки, подзаголовок; размеры «экран» и 3200 px; 5 скачиваний в месяц.
- **Pro**: ручная настройка всего (цвета, вода, картуш, роза, рамка, маршруты, значки, корабли, свои надписи, перемещение элементов), A3 и A2 в 300 dpi, скачивания без лимита.

Ограничения Lite проверяет сервер, поэтому обойти их из браузера нельзя. Оплата пока не подключена. Кто нажал «Хочу Pro», виден в D1: `SELECT email FROM users WHERE pro_requested = 1;`
Выдать Pro: `UPDATE users SET plan = 'pro' WHERE email = 'почта@пример';`
Следующий шаг — подключить Stripe или Paddle.

## Конфиденциальность: как это устроено
- Карта закрыта по умолчанию. `/m/<id>` открывается другим людям только после включения доступа в меню «Поделиться». Выключить доступ можно в любой момент.
- Пароли хранятся как PBKDF2-хэш. Сессия хранится в HttpOnly-cookie, в базе лежит только её хэш.
- Для поиска на карте в OpenStreetMap уходит только название места.
- Удаление карты и аккаунта стирает всё, включая историю разговора и снимки для отката. Заказы печати остаются (сроки хранения для налоговой), но отвязываются от аккаунта.
- ИИ: Workers AI (Cloudflare) или Claude API, если задан `ANTHROPIC_API_KEY`. Оба провайдера по умолчанию не обучают модели на запросах через API.

## Что где
- `lib/scenarios.js` — сценарии интервью (описаны в `SCENARIOS.md`).
- `lib/auth.js`, `functions/api/auth/*` — регистрация, вход, Google, удаление аккаунта.
- `public/assets/basemap.js` — векторная подложка; `public/geo` — её данные.
- `lib/print.js`, `functions/api/print/*`, `public/assets/print.js` — печать.
- `lib/legal.js` — Impressum, Datenschutz, AGB. `lib/rate.js` — лимиты. `lib/mail.js` — письма.
- `public/assets/poster.js` — композиция и экспорт PNG.
